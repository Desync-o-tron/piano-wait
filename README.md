# PianoWait

An open-source iOS practice app that listens to an acoustic piano through the iPhone microphone and waits for you to play the right notes.

## Features

- **Acoustic Piano Pitch & Chord Detection**: Real-time polyphonic pitch detection using `Accelerate` (`vDSP`) with harmonic salience evaluation, octave-overtone rejection, and live piano tuning offset tracking.
- **Wait-for-Me Mode**: Advances the falling-note playhead up to each chord/step and waits until all required notes are played on your acoustic piano, with rolled-chord grace and strike memory.
- **Continuous Play-Along Mode**: Adjustable speed (`0.25x`–`2.0x`), A–B section looping, hand selection (`Both`, `Right`, `Left`), optional accompaniment synth, and interactive progress scrubbing.
- **Built-in & Imported MIDI Library**: Ships with public-domain classical starter pieces (`Ode to Joy`, `Minuet in G`, `Für Elise`) and supports importing any Standard MIDI File (`.mid` / `.midi`) via the iOS Files picker or an optional self-hosted cloud bucket.

## Layout

| Path | Contents |
| --- | --- |
| `Sources/PianoWaitCore` | Standard MIDI parser, acoustic pitch detector, wait-mode engine, synthesizer, optional cloud bucket client |
| `App` | SwiftUI iOS app |
| `Tests/PianoWaitCoreTests` | Unit, integration, and end-to-end simulation tests |
| `UITests/PianoWaitUITests` | Simulator UI tests |
| `samples` | Public-domain sample MIDI files generated by `swift run pianowait-samples` |
| `tools` | Optional cloud bucket upload helpers and app icon generator |

## Build and test

```sh
swift test
xcodebuild test -scheme PianoWait -destination 'platform=iOS Simulator,name=iPhone 17'
xcodebuild -scheme PianoWait -destination generic/platform=iOS build
```

To deploy to your own iPhone, open `PianoWait.xcodeproj` in Xcode and select your Apple ID / Development Team under **Signing & Capabilities** (or pass `DEVELOPMENT_TEAM=<YOUR_TEAM_ID> PRODUCT_BUNDLE_IDENTIFIER=<your.bundle.id>` on the `xcodebuild` command line).
